\section{First Step: prepare the development environment}

In this section, you will find the tasks to do for preparing your development environment.

\subsection{Installation of the Eclipse Tools}

\begin{emphbox}
Recommended version of SARL : \sarlversion\ (stable)
\end{emphbox}

\begin{enumerate}
\item Download the \Emph{Eclipse product} that contains the compilation tools for the SARL programming language : \url{http://www.sarl.io}
\item Uncompress the Eclipse product for SARL.
\item Launch the downloaded Eclipse product.
\item Create a project by using one of the two methods that are explained below: the regular SARL project (Section \ref{section:createsarlproject}), \Emph{OR} Maven+SARL project (Section \ref{section:createsarlmavenproject}).
\end{enumerate}

\subsubsection{Create a regular SARL project}\label{section:createsarlproject}

\begin{enumerate}
\item Open the wizard for creating a SARL project, with the menu: \\
	\texttt{> File > New > Project > SARL > SARL Project}
\item Enter the name of the project.
\ifJANUSINCLASSPATH
\item Because the code template of this lab work requires several functions that are provided by Janus, you must install the Janus sarl run-time environment in the libraries of your project:
	\item Click on the tab with the name \code{Libraries}.
	\item In the list of the libraries, remove the \code{SARL Libraries}.
	\item In the list of the libraries, add the \code{Janus Libraries}.
\fi
\item Click on "Finish", the SARL project should be created.
\item You must ensure that the configuration of your SARL project is correct (may be still a bug in the SARL environment):
	\begin{enumerate}[a)]
	\item Open the dialog of the properties of the SARL project by clicking on: \\
		\texttt{Right click on project > Properties > SARL > Compiler > Output Folder}
	\item Check if the field ``Directory'' is set to a source folder that is existing in your SARL project. If not change the property with): \\
		\texttt{src/main/generated-sources/sarl}
	\end{enumerate}
\end{enumerate}

Your Eclipse environment is now ready for the lab work session.
\ifCODESKELETON
You should now install the code skeleton provided by the teachers (see the section below).
\fi

\subsubsection{Create a SARL+Maven project}\label{section:createsarlmavenproject}

Maven is a standard tool for managing and compiling a project. SARL development environment provides a Maven plugin for compiling SARL program, so that it is possible to use Maven for your SARL projects.
Maven has the advantage of downloading automatically from Internet the Java libraries that are required for compiling and running the project.

For creating a SARL+Maven project, you have to apply the following steps:

\ifCODESKELETON
	\begin{enumerate}
	\item Open the wizard for creating a SARL project, with the menu: \\
		\texttt{> File > New > Project > SARL > SARL Maven Project}
	\item Check the box "Create a simple project".
	\item Click on "Next".
	\item Enter an Artifact and a Group Id.
	\item Click on "Finish", the SARL project should be created.
	\end{enumerate}
\else
	\ifJANUSINCLASSPATH
		\begin{enumerate}
		\item Open the wizard for creating a SARL project, with the menu: \\
			\texttt{> File > New > Project > SARL > SARL Maven Project}
		\item Check the box "Create a simple project".
		\item Click on "Next".
		\item Enter an Artifact and a Group Id.
		\item Click on "Finish", the SARL project should be created.
		\item Because, your project must use some internal geatures of the Janus run-time framework (the run-time environment behing SARL), you must put Janus as an explicit dependency of your project. Add the following depencency in the \texttt{pom.xml} file:
			\begin{itemize}
			\item Group Id: \texttt{io.janusproject}
			\item Artifact Id: \texttt{io.janusproject.kernel}
			\item Version: \texttt{3.\sarlversion}
			\end{itemize}
		\end{enumerate}
	\else
		\begin{enumerate}
		\item Open the wizard for creating a SARL project, with the menu: \\
			\texttt{> File > New > Project > SARL > SARL Maven Project}
		\item Check the box "Create a simple project".
		\item Click on "Next".
		\item Enter an Artifact and a Group Id.
		\item Click on "Finish", the SARL project should be created.
		\end{enumerate}
	\fi
\fi

	\subsection{Installation of the Code Skeleton}

	The teachers provide a code skeleton that should be completed by you for finishing the tasks related to this lab work session.
	The steps to follow for installing the code skeleton are:
	\begin{enumerate}
	\item Get the Zip/Jar Archive file that contains the code skeleton: \skeletonName.
	\item Do not uncompress the Zip/Jar file.
	\item Open the wizard for importing the code skeleton into the SARL project: \\
		\texttt{Right click on project > Import > General > Archive File}
	\item Select on the local file system the downloaded file of the code skeleton.
	\item Check the box ``Overwrite existing resources without warning''.
	\item Click on ``Finish''.
	\item If the SARL environment ask you to overwrite an existing file, answer ``Yes''.
	\item Force Maven to update the project configuration: \\
		\texttt{Right click on the project > Maven > Update Project}
	\item Clean the workspace for ensuring that each existing file is compiled: \\
		\texttt{Menu > Project > Clean}
	\item The source folders of your project shall contains SARL and Java code. \\
		Some errors are appearing since they are related to the missed part of the code that must be provided by you. 
	\end{enumerate}
